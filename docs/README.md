# ISRPO-lab2-documentation

## Общее описание решения

Набор функций для вычисления площади и периметра (длины окружности) геометрических фигур:

- круг (`circle.py`);
- квадрат (`square.py`);
- треугольник (`triangle.py`).

Все функциипринимают числа и возвращают число - результат вычисления.

---

## Описание функций и примеры вызова

### circle.py

#### area(r)
Принимает радиус окружности `r`, возвращает площадь круга.

```python
area(9)  # 254.4615
```

#### perimeter(r)
Принимает радиус окружности `r`, возвращает длину окружности.

```python
perimeter(9)  # 56.547
```

---

### square.py

#### area(a)
Принимает сторону квадрата `a`, возвращает площадь квадрата.

```python
area(12)  # 144
```

#### perimeter(a)
Принимает сторону квадрата `a`, возвращает периметр квадрата.

```python
perimeter(12)  # 48
```

---

### triangle.py

#### area(a, h)
Принимает сторону треугольника `a` и высоту `h`, возвращает площадь треугольника.

```python
area(4, 6) # 12
```

#### perimeter(a, b, c)
Принимает стороны треугольника `a`, `b`, `c`, возвращает периметр треугольника.

```python
perimeter(3, 4, 5) # 12
```
